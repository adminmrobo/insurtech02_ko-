조건부 확률로 쓰면

청구자만 정확도 = P(예측 = 청구 | 실제 = 청구) = TP ÷ (TP + FN) = 666 ÷ 927 = 0.7184
= 재현율(Recall) = 민감도(Sensitivity) = TPR

미청구자만 정확도 = P(예측 = 없음 | 실제 = 없음) = TN ÷ (TN + FP) = 49,872 ÷ 62,399 = 0.7992
= 특이도(Specificity) = TNR

반대로 열(판정) 방향으로 읽으면 정밀도 P(실제 = 청구 | 예측 = 청구) = 666 ÷ 13,193 = 0.0505 입니다. 조건이 뒤집히면 전혀 다른 숫자가 됩니다.

문항 1의 전체 정확도와의 관계Accuracy = π·TPR + (1−π)·TNR

임계값과 청구 비율을 바꿔 보세요. π가 작으면 전체 정확도는 TNR에 붙어 다닙니다.

전체 정확도는 두 조건부 정확도의 가중 평균입니다. 가중치는 각 그룹의 비율입니다.

전체 정확도 = π × TPR + (1 − π) × TNR    (π = 청구 비율 = 0.0146)

✎ 보고서 답안 틀

정의. 청구자만 대상 정확도 = P(Ŷ=1 | Y=1) = TP/(TP+FN) = 재현율(민감도, TPR). 미청구자만 대상 정확도 = P(Ŷ=0 | Y=0) = TN/(TN+FP) = 특이도(TNR).

결과 (로지스틱, 5-Fold 검증 예측, 임계값 0.5). TPR = 666/927 = 0.7184, TNR = 49,872/62,399 = 0.7992.

관계. 전체 정확도 = π·TPR + (1−π)·TNR = 0.0146×0.7184 + 0.9854×0.7992 = 0.7981 (문항 1의 5-Fold 평균 정확도 0.7981과 일치). π가 1.46%로 작아 전체 정확도는 거의 TNR로 정해지며, 청구자 판정 성능(TPR)은 전체 정확도에 1.46%의 가중치로만 반영된다.

조건부 확률
“~인 사람들 중에서”. P(A | B) = B인 경우만 놓고 A의 비율. 세로줄 오른쪽이 분모.
재현율 · 민감도 (TPR)
청구자 그물. P(예측=청구 | 실제=청구).
특이도 (TNR)
미청구자를 미청구로. P(예측=없음 | 실제=없음).
정밀도 (Precision)
그물 속 순도. P(실제=청구 | 예측=청구). 조건이 뒤집힌 값.
기저율 π
원래 비율. 전체 중 청구 비율 0.0146.
균형 정확도
두 그룹을 같은 무게로. (TPR + TNR) ÷ 2. 불균형에서 정확도 대신 쓴다.
