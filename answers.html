확인 문제 (4개)

문제 1

Q1. 과제가 KFold 가 아니라 StratifiedKFold 를 요구하는 가장 큰 이유는?

  1. 계산이 더 빠르기 때문
    오해: 속도는 거의 같습니다.
  2. fold마다 청구 비율을 같게 맞춰, 청구가 적은 fold 때문에 점수가 흔들리지 않게 하려고 ✔ 정답
  3. 데이터를 늘려 주기 때문
    오해: 층화는 데이터를 늘리지 않습니다. 나누는 방식만 바꿉니다.

해설 섞지 않은 KFold 는 fold별 청구 수가 87~254명, 섞은 KFold 도 157~202명이지만, StratifiedKFold 는 185~186명으로 고릅니다.

배점 2점 · 정답 + 이유 한 문장 = 2점, 정답만 = 1점, 오답이어도 핵심 이유를 말하면 1점

문제 2

Q2. 기준선의 5-Fold 평균 정확도(98.54%)가 모든 모델보다 높습니다. 올바른 해석은?

  1. 기준선이 가장 좋은 모델이다
    오해: 기준선은 청구 고객을 한 명도 찾지 못합니다(재현율 0).
  2. 이 데이터에서는 정확도가 미청구 고객 판정에 지배되므로, 정확도로 모델을 고르면 안 된다 ✔ 정답
  3. 모델에 버그가 있다
    오해: 모델은 청구 고객을 50~72% 찾아냅니다. 정확도가 낮은 것은 오탐 때문입니다.

해설 정확도 = π·TPR + (1−π)·TNR 이고 π=1.46%라 거의 TNR 과 같습니다(2편).

배점 2점 · 정답 + 이유 한 문장 = 2점, 정답만 = 1점, 오답이어도 핵심 이유를 말하면 1점

문제 3

Q3. 표준화(StandardScaler)를 Pipeline 안에 넣은 이유는?

  1. 코드가 짧아져서
    오해: 그것도 장점이지만 핵심은 아닙니다.
  2. fold마다 학습 데이터로만 평균·표준편차를 계산해, 검증 fold 정보가 새어 들어가지 않게(누수 방지) ✔ 정답
  3. Pipeline 이 class_weight 를 자동으로 정해서
    오해: class_weight 는 모델 설정입니다.

해설 전체 데이터로 표준화한 뒤 나누면 검증 fold 의 평균·분산이 학습에 섞입니다. 과제 제약 3번(누수 금지)에 해당합니다.

배점 2점 · 정답 + 이유 한 문장 = 2점, 정답만 = 1점, 오답이어도 핵심 이유를 말하면 1점

문제 4

  1. 재현율 0.773 (가장 좋은 fold)
    오해: 가장 좋은 fold 만 고르면 과장입니다.

확인 문제 (3개)

문제 1

Q1. “청구자만 대상 정확도”를 조건부 확률로 쓰면?

  1. P(실제 = 청구 | 예측 = 청구)
    오해: 그것은 정밀도입니다. 조건(세로줄 오른쪽)이 “예측 = 청구”입니다.
  2. P(예측 = 청구 | 실제 = 청구) ✔ 정답
  3. P(예측 = 실제)
    오해: 그것은 전체 정확도입니다.

해설 조건이 “실제 = 청구”이므로 분모는 실제 청구자 927명입니다. 재현율(TPR)과 같습니다.

배점 2점 · 정답 + 이유 한 문장 = 2점, 정답만 = 1점, 오답이어도 핵심 이유를 말하면 1점

문제 2

Q2. 로지스틱의 TPR 0.7184, TNR 0.7992, π 0.0146 일 때 전체 정확도에 가장 가까운 값은?

  1. (0.7184 + 0.7992) ÷ 2 = 0.7588
    오해: 그것은 균형 정확도입니다. 두 그룹의 크기를 같게 본 값입니다.
  2. 0.0146 × 0.7184 + 0.9854 × 0.7992 ≈ 0.7981 ✔ 정답
  3. 0.7184 × 0.7992 ≈ 0.574
    오해: 곱이 아니라 가중 평균입니다.

해설 가중치가 그룹 비율이라, 청구 비율이 작을수록 전체 정확도는 TNR에 가까워집니다.

배점 2점 · 정답 + 이유 한 문장 = 2점, 정답만 = 1점, 오답이어도 핵심 이유를 말하면 1점

문제 3

Q3. 임계값을 낮추면(더 많이 “청구”라고 판정하면) 두 조건부 정확도는?

  1. 둘 다 오른다
    오해: 더 많이 청구라고 하면 미청구자를 청구로 잘못 판정하는 일도 늘어 TNR은 내려갑니다.
  2. TPR은 오르고 TNR은 내려간다 ✔ 정답
  3. 둘 다 그대로다
    오해: 임계값은 혼동행렬 네 칸을 모두 바꿉니다.

해설 임계값 슬라이더에서 확인할 수 있습니다. 극단으로 가면 “모두 청구”(TPR 1, TNR 0)가 됩니다.

배점 2점 · 정답 + 이유 한 문장 = 2점, 정답만 = 1점, 오답이어도 핵심 이유를 말하면 1점

강의 멘트

정의

도입 청구자만 정확도와 미청구자만 정확도를 조건부 확률로 씁니다.

시연 청구자만 정확도의 분모는 무엇일까요?

질문 로지스틱의 TP 와 FN 은 각각 몇 명인가요?

정리 P(예측=청구 | 실제=청구) = 재현율. 오해: 정밀도와 혼동.

두 그룹 비교

도입 다섯 모델과 극단 모델 두 개를 나란히 봅니다.

시연 “모두 청구” 모델의 청구자만 정확도는 얼마일까요?

질문 두 값이 서로 반대로 움직이는 모델을 찾아보세요.

정리 TPR 과 TNR 은 교환 관계. 한쪽만 보고하지 않는다.

전체 정확도와의 관계

도입 전체 정확도 = π·TPR + (1−π)·TNR 을 확인합니다.

시연 π 를 50%로 올리면 보라 점선은 어느 쪽으로 갈까요?

질문 실제 π 에서 전체 정확도는 TPR 과 TNR 중 어느 쪽에 가까운가요?

정리 청구 비율이 작으면 전체 정확도 ≈ TNR.

  3. 브라우저는 소수 계산을 못해서
    오해: JS 는 sklearn 과 소수점 아래 15자리까지 같은 값을 냅니다(이 페이지 검증).

  3. 성별은 판정에 영향이 없어서
